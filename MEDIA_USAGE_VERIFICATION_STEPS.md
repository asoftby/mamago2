## 🚀 Шаги для проверки

### 1. Перезапустить dev server

```bash
# Если dev server запущен - остановить (Ctrl+C)
pnpm dev
```

### 2. Открыть страницу медиа в браузере

```
http://localhost:3000/admin/media/cmovam68x000dws4w3o2vro1v
```

**Ожидаемый результат**:
- ✅ "Использование (1)" вместо "Использование (0)"
- ✅ В секции "Использование" показано:
  - EVENT
  - Тестовое событие от Британской школы
  - coverImageId
  - Ссылка "Открыть →"

### 3. Проверить кнопку "Пересчитать usage"

1. Кликнуть кнопку "Пересчитать usage"
2. Дождаться сообщения об успехе
3. Проверить, что счётчик остался 1

### 4. Создать новое событие с изображением

1. Перейти в `/business/events/new`
2. Создать событие
3. Добавить cover image (выбрать любое изображение)
4. Сохранить
5. Перейти на страницу этого изображения в медиатеке
6. Проверить, что "Использование (1)"

### 5. Обновить cover image существующего события

1. Открыть событие "Тестовое событие от Британской школы"
2. Изменить cover image на другое
3. Сохранить
4. Проверить старое изображение: "Использование (0)"
5. Проверить новое изображение: "Использование (1)"

## 🔍 Если что-то не работает

### Проблема: UI показывает 0 после перезагрузки

**Решение**: Очистить кэш браузера (Cmd+Shift+R на Mac)

### Проблема: Sync не создаёт MediaUsage

**Проверка**:
```bash
npx tsx scripts/test-sync-media-usage.ts
```

Если ошибка - проверить:
1. Миграция применена: `pnpm prisma migrate status`
2. Prisma Client регенерирован: `pnpm prisma generate`

### Проблема: Кнопка "Пересчитать usage" не работает

**Проверка**: Открыть DevTools → Network → кликнуть кнопку → проверить запрос к `/api/admin/media/recompute-usage`

Если 401/403 - проверить, что залогинены как ADMIN
