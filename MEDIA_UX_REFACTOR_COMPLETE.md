# Media UX Refactor Complete

## Проблема
Кнопка "Редактировать" находилась в блоке "Информация о файле", что создавало ожидание редактирования технических свойств файла (filename, extension и т.д.). Это неправильная UX-иерархия.

## Решение
Переработана UX страницы медиафайла:
- Блок "Информация о файле" стал полностью read-only
- Кнопка "Редактировать" перенесена в блок "Метаданные"
- Редактируются только смысловые поля: title, alt, caption
- Технические свойства файла не редактируются

## Изменения

### 1. Блок "Информация о файле" - Read-only

Теперь содержит только просмотр:
- Имя файла (displayFilename)
- Оригинальное имя
- Тип файла
- Размер
- Размеры (width × height)
- Длительность (для видео)
- MIME тип (визуально вторично)
- Расширение (визуально вторично)

Никаких edit actions в этом блоке нет.

### 2. Блок "Метаданные" - Главный редактируемый блок

Структура:
```
Метаданные                    [Редактировать]

Заголовок: "Логотип Пуговка"  [Авто]
Alt текст: "Логотип места..."  [Авто]
Описание: "Логотип Пуговка"   [Авто]
```

При нажатии "Редактировать":
- [✨ Заполнить автоматически]
- Заголовок: [input с placeholder]
- Alt текст: [input с placeholder]
- Описание: [textarea с placeholder]
- [Сохранить] [Отмена]

### 3. Убрано редактирование filename

Удалено из:
- `MediaMetadataEditor` component - убрано поле filename
- `UpdateMediaMetadataInput` interface - убран filename
- `updateMediaMetadata` service - убрана валидация filename
- `PATCH /api/admin/media/[id]` - убран filename из body

### 4. Визуальная иерархия

**Правая колонка (сверху вниз):**
1. Информация о файле (read-only, технический блок)
2. **Метаданные** (главный редактируемый блок) ⭐
3. Использование (usage map)
4. Системная информация (даты, источник)
5. Техническая информация (collapsible)

Блок "Метаданные" визуально воспринимается как основной продуктовый блок для управления смыслом изображения.

## Результат

### До:
- Кнопка "Редактировать" в блоке "Информация о файле"
- Ожидание редактирования filename
- Неясная UX-иерархия

### После:
- Блок "Информация о файле" - read-only
- Кнопка "Редактировать" в блоке "Метаданные"
- Редактируются только title, alt, caption
- Четкая UX-иерархия: технические свойства vs смысловые метаданные

## Использование

1. Открыть `/admin/media/[id]`
2. Просмотреть "Информацию о файле" (read-only)
3. В блоке "Метаданные" нажать "Редактировать"
4. Опционально нажать "Заполнить автоматически" ✨
5. Отредактировать title, alt, caption
6. Нажать "Сохранить"
7. Метаданные обновятся, badges изменятся на "Вручную"
