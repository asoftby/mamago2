## Что изменено

### 1. ✅ Hero block стал компактнее

**Было**:

**Стало**:

**Экономия высоты**: ~40px

### 2. ✅ Объединены первые два преимущества

**Было** (4 пункта):
1. Для всей семьи — Добавьте детей и взрослых — план станет персональнее
2. Точнее подборка — Учитываем возраст, интересы и формат отдыха
3. Собрать день проще — Утро, день и вечер — в одном понятном сценарии
4. Сохраняйте идеи — Понравилось событие или маршрут — добавьте и вернитесь позже

**Стало** (3 пункта):
1. **Для всей семьи** — Учитываем интересы детей и взрослых, чтобы план был персональнее
2. **Готовый сценарий дня** — Утро, день и вечер — в одном понятном плане
3. **Сохраняйте идеи** — Понравилось событие или маршрут — добавьте и вернитесь позже

**Изменения**:
- Пункты 1 и 2 объединены в один
- Пункт 3 переименован: "Собрать день проще" → "Готовый сценарий дня"
- Более сильная формулировка value proposition

### 3. ✅ Benefit section стала компактнее

**Spacing изменения**:
- Icon size: 36px → 32px (w-9 h-9 → w-8 h-8)
- Icon size внутри: 20px → 16px (w-5 h-5 → w-4 h-4)
- Gap между items: 12px → 10px (space-y-3 → space-y-2.5)
- Gap между icon и text: 12px → 10px (gap-3 → gap-2.5)
- Section padding: py-2 → убран (теперь в общем контейнере)

**Экономия высоты**: ~50px

### 4. ✅ Timeline Preview вместо абстрактного списка

**Было**: "Пример плана"
- Простые карточки с временем слева
- Утро / День / Вечер
- Без визуальной связи между элементами
- Выглядело как декоративный мок

**Стало**: "Сценарий дня"
- Вертикальная timeline линия (2px, primary/20)
- Точки-маркеры на линии (16px, primary color)
- Конкретное время (09:30, 13:00, 16:30, 19:00)
- 4 шага вместо 3
- Визуально читается как последовательность
- Выглядит как preview реального продукта

**Компоненты**:
```tsx
<TimelineStep>
  - Вертикальная линия (absolute, left-[7px])
  - Точка-маркер (w-4 h-4, bg-primary, border-2 white)
  - Время (text-xs, font-semibold, primary color)
  - Название активности (text-sm, font-medium)
```

**Активности**:
1. 09:30 — Детская библиотека
2. 13:00 — Мастер-класс по рисованию
3. 16:30 — Прогулка по маршруту в парке
4. 19:00 — Семейное кафе
