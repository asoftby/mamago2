## Стоимость и доступ

Основной список сортирует уже загруженные предложения. В разделе публикаций к существующему Prisma select добавлена связь boosts с условием startAt ≤ now < endAt, сортировкой endAt desc и take 1. Результат для одной карточки содержит признак продвижения и одну дату. Запросов из цикла карточек нет. Количество физических SQL-запросов зависит от стратегии загрузки связей Prisma. Сервис кандидатов WIP дополнительно выбирает обложку. Общего кеша приватных данных и новых платных внешних вызовов эти изменения не добавляют. На рабочем объёме SQL-трасса, размер ответа и p95 не измерялись.
