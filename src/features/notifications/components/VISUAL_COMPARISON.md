# Визуальное сравнение: До и После

## До унификации

### Telegram уведомление
```
┌─────────────────────────────────────────────────┐
│ [→] Подключите Telegram, чтобы не пропускать... │
│                              [Подключить]       │
└─────────────────────────────────────────────────┘
```
- Горизонтальный layout
- Кнопка справа
- Одна строка текста
- Нет заголовка

### Email уведомление
```
┌─────────────────────────────────────────────────┐
│                                            [X]  │
│ [✉] Подтвердите email                          │
│     Чтобы сохранить доступ к вашим идеям,      │
│     планам и важным действиям в mamaGo,        │
│     подтвердите email.                         │
│                                                 │
│                    [Отправить письмо]          │
└─────────────────────────────────────────────────┘
```
- Вертикальный layout
- Кнопка снизу (но не full-width на desktop)
- Длинный текст
- Есть заголовок

**Проблема**: Разная структура, разная позиция кнопки, разная иерархия

---

## После унификации

### Telegram уведомление
```
┌─────────────────────────────────────────────────┐
│ [→] Подключите Telegram                        │
│     Чтобы не пропускать важные уведомления     │
│     и ответы.                                  │
│                                                 │
│ [        Подключить        ]                   │
└─────────────────────────────────────────────────┘
```

### Email уведомление
```
┌─────────────────────────────────────────────────┐
│ [✉] Подтвердите email                     [X]  │
│     Чтобы сохранить доступ к вашим идеям,      │
│     планам и важным действиям.                 │
│                                                 │
│ [      Отправить письмо     ]                  │
└─────────────────────────────────────────────────┘
```

**Решение**: Единая структура, единая позиция кнопки, единая иерархия

---

## Единые параметры

| Параметр | Значение |
|----------|----------|
| Иконка размер | 4x4 (h-4 w-4) |
| Иконка stroke | 1.75 |
| Title размер | text-sm |
| Title вес | font-semibold |
| Description размер | text-xs sm:text-sm |
| Description leading | leading-snug |
| Button ширина | w-full |
| Button цвет | bg-[#EF8759] |
| Border radius | rounded-lg |
| Padding | px-4 py-3 |
| Gap | gap-3 |

---

## Цветовая семантика

### Telegram (голубой)
- Container: `border-sky-200 bg-sky-50/90`
- Icon: `text-sky-600`
- Title: `text-sky-950`
- Description: `text-sky-900/85`

### Email (тёплый)
- Container: `border-amber-200 bg-amber-50/90`
- Icon: `text-amber-700`
- Title: `text-amber-950`
- Description: `text-amber-900/85`

---

## Адаптивность

### Mobile (< 640px)
- Description: `text-xs`
- Full-width button
- Вертикальный layout

### Desktop (≥ 640px)
- Description: `text-sm`
- Full-width button
- Вертикальный layout

**Важно**: Кнопка всегда full-width на всех разрешениях для единообразия

## Состояния

### Default
```
┌─────────────────────────────────────┐
│ [icon] Title                        │
│        Description                  │
│                                     │
│ [Action Button]                    │
└─────────────────────────────────────┘
```

### With Dismiss
```
┌─────────────────────────────────────┐
│ [icon] Title                   [X]  │
│        Description                  │
│                                     │
│ [Action Button]                    │
└─────────────────────────────────────┘
```

### Loading
```
┌─────────────────────────────────────┐
│ [icon] Title                   [X]  │
│        Description                  │
│                                     │
│ [Загрузка…] (disabled)             │
└─────────────────────────────────────┘
```

---

## Преимущества унификации

✅ **Визуальная консистентность**: все карточки выглядят как часть одной системы  
✅ **Предсказуемость**: пользователь знает, где искать действие  
✅ **Масштабируемость**: легко добавить новый тип уведомления  
✅ **Поддерживаемость**: один компонент вместо N разных реализаций  
✅ **Семантика**: цвет сохраняет смысл, структура — единая
