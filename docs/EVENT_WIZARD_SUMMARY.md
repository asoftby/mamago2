# Event Wizard - Implementation Summary

## Overview
Event Wizard - пошаговый мастер создания и редактирования событий для business/admin части mamaGo. Архитектура основана на Place Wizard, но с event-специфичной бизнес-логикой.

## Структура шагов

### 9 шагов создания события:
1. **Основное** - название, тип активности, категории, возраст
2. **Описание** - краткое и полное описание
3. **Медиа** - обложка, галерея, видео
4. **Дата и время** - даты проведения, время, повторяющиеся события
5. **Стоимость** - бесплатно/платно, цена, ссылка на билеты
6. **Локация** - выбор существующего места или ручной ввод
7. **Контакты** - телефон, сайт, соцсети
8. **Организатор** - название и описание организатора
9. **Проверка** - финальный review и отправка

## Особенности реализации

### Условная логика
- Если выбрана категория "Кино" → показать доп. поля (жанр, длительность, трейлер)
- Если не "Бесплатно" → показать поле цены и ссылки на билеты
- Если не "Весь день" → показать время начала и окончания

### Сложные компоненты
- **Множественные даты** - возможность добавить несколько дат проведения
- **Повторяющиеся события** - настройка периодичности (день/неделя/месяц/год)
- **Список соцсетей** - динамический список с типом и ссылкой
- **Выбор локации** - два режима (существующее место или ручной ввод)

### Автосохранение
- Дебаунс 2 секунды
- Тихое сохранение (без success-тостов)
- Показ только ошибок
- Восстановление из localStorage

## План реализации

### Phase 1: Foundation (Фундамент)
- Извлечь shared компоненты из Place Wizard
- Создать event data model
- Создать event validation schemas
- Создать event step configuration

### Phase 2-4: Steps Implementation (Шаги 1-9)
- Реализовать все 9 шагов
- Добавить валидацию на каждом шаге
- Добавить автосохранение

### Phase 5: Integration (Интеграция)
- Создать главный EventWizard контейнер
- Создать useEventWizard hook
- Создать страницы /events/new и /events/[id]/edit

### Phase 6: Polish (Полировка)
- Мобильная адаптация
- Доступность (a11y)
- Обработка ошибок
- Документация

### Phase 7: Deployment (Деплой)
- Тестирование
- Деплой в staging
- Деплой в production
- Мониторинг
