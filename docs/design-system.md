# Design System - mamaGo 2.0

## Principles
- **Airbnb-like + Warm**: Clean, minimal, but friendly and approachable.
- **Card-based**: Content is organized in distinct, rounded cards.
- **Light Theme Friendly**: Optimized for bright, airy interfaces.

## Colors

| Token | Hex | Usage |
|-------|-----|-------|
| **Primary** | `#EF8759` | Brand color, primary actions, active states |
| **Background** | `#F7F7F5` | Page background (warm grey/white) |
| **Text** | `#1F1F1F` | Primary text color |
| **Muted** | `#6B6B6B` | Secondary text, icons, de-emphasized content |
| **Border** | `#ECEAE6` | Dividers, card borders |
| **Success** | `#2FBF71` | Success states, positive indicators |
| **Warning** | `#F2A93B` | Warnings, ratings/stars |

## Radii
- **Card**: `18px`
- **Button**: `16px`
- **Standard**: `0.625rem` (10px) - inherited from shadcn default

## Shadows
- **Card**: `0 6px 18px rgba(0,0,0,0.06)`

## Typography
**Font Family**: Manrope

| Role | Size / Weight | Description |
|------|---------------|-------------|
| **H1** | 26px / 700 | Main page titles |
| **H2** | 20px / 600 | Section headers |
| **CardTitle** | 16px / 600 | Card headings |
| **Body** | 14px / 400 | Standard text |
| **Meta** | 12px / 500 | Metadata, captions, secondary info |

## Grid & Spacing
- **Base Grid**: 8pt
- **Spacing Scale**: 8, 12, 16, 20, 24, 32 px
