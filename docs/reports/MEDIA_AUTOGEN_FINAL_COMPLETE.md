# Media Auto-generation System - Final Implementation

## Реализовано

### 1. ✅ Автогенерация метаданных по контексту

Система автоматически генерирует осмысленные metadata на основе:
- `entityType` - тип сущности (PLACE, EVENT, OFFER, ROUTE, ARTICLE, USER, STORY)
- `entityTitle` - название сущности
- `field` - роль изображения (cover, logo, gallery, avatar и т.д.)

### 2. ✅ Приоритеты значений

```
displayTitle = media.title ?? autoTitle ?? filename
displayAlt = media.alt ?? autoAlt ?? filename
displayCaption = media.caption ?? autoCaption ?? null
```

1. Ручное значение (manual)
2. Автогенерация (auto)
3. Fallback (filename)

### 4. ✅ UI с badges источника

На странице `/admin/media/[id]` в блоке "Метаданные":
- Badge "Вручную" (зеленый) - для ручных значений
- Badge "Авто" (синий) - для автогенерированных значений
- Без badge - для fallback значений

### 5. ✅ Кнопка "Заполнить автоматически"

В редакторе метаданных:
- Кнопка с иконкой ✨ "Заполнить автоматически"
- Копирует автогенерированные значения в форму
- После сохранения они становятся ручными значениями
- Позволяет быстро стартовать от шаблона

### 6. ✅ Список медиатеки показывает displayTitle

На странице `/admin/media`:
- Основной текст: `media.title` (если есть) или `displayFilename`
- Второй текст: `displayFilename` (если отличается от основного)
- Осмысленные названия вместо технических

### 7. ✅ Редактирование метаданных

- Inline editing на detail page
- Поля: filename, alt, title, caption
- Автогенерированные значения как placeholders
- Сохранение без перезагрузки страницы

## Использование

### В админке:

1. **Просмотр автогенерации:**
   - Открыть `/admin/media/[id]`
   - Увидеть метаданные с badges "Авто"/"Вручную"
   - Синяя подсказка показывает контекст автогенерации

2. **Быстрое заполнение:**
   - Нажать "Редактировать"
   - Нажать "Заполнить автоматически" ✨
   - Отредактировать при необходимости
   - Нажать "Сохранить"

3. **Ручное редактирование:**
   - Нажать "Редактировать"
   - Заполнить поля вручную
   - Нажать "Сохранить"
   - Badge изменится на "Вручную"

### В списке медиатеки:

- Показываются осмысленные названия (title) вместо технических filename
- Если title заполнен вручную - показывается он
- Если нет - показывается displayFilename
