# 📱 Инструкции для тестирования мобильного поиска

## 🎯 Цель
Проверить, что мобильные фильтры поиска отображаются и сохраняются правильно.

## 🔧 Подготовка
1. Убедитесь, что сервер запущен: `npm run dev`
2. Откройте браузер и перейдите на http://localhost:3000/minsk
3. Откройте DevTools (F12)
4. Включите мобильный режим (Toggle device toolbar) или Ctrl+Shift+M
5. Выберите iPhone или другое мобильное устройство
6. Обновите страницу

## ✅ Что должно быть видно

### В мобильном режиме:
- ✅ Зеленая метка "Mobile Header Active" в левом верхнем углу
- ✅ Строка поиска с иконкой и текстом "Начать поиск"
- ✅ Красная метка "NO filters" или "HAS filters" справа от строки поиска

### При клике на строку поиска:
- ✅ Открывается полноэкранный мобильный поиск
- ✅ Видны категории (Куда пойти, Кружки, и т.д.)
- ✅ Видны секции: Где?, Когда, Кто

## 🧪 Тестовые сценарии

### Сценарий 1: Без фильтров
1. Перейдите на http://localhost:3000/minsk
2. **Ожидаемый результат**: "Начать поиск" + "NO filters"

### Сценарий 2: С возрастным фильтром
1. Перейдите на http://localhost:3000/minsk?age=0-1
2. **Ожидаемый результат**: "Минск • 0–1 год" + "HAS filters"

### Сценарий 3: С фильтром даты
1. Перейдите на http://localhost:3000/minsk?preset=TODAY
2. **Ожидаемый результат**: "Минск • Сегодня" + "HAS filters"

### Сценарий 4: С фильтром метро
1. Перейдите на http://localhost:3000/minsk?metro=cmmj6x1s5000hws428w3qtxqy
2. **Ожидаемый результат**: "Минск • Каменная Горка" + "HAS filters"

### Сценарий 5: Несколько фильтров
1. Перейдите на http://localhost:3000/minsk?age=0-1,1-3&preset=TOMORROW
2. **Ожидаемый результат**: "Минск • Завтра • 0–1 год, 1–3 года" + "HAS filters"

## 🔍 Диагностика
Если что-то не работает, проверьте:

1. **Консоль браузера** - должны быть логи с 🔍 MobileSearchEntry
2. **Диагностическая страница** - http://localhost:3000/debug-mobile-search?age=0-1&preset=TODAY
3. **Network tab** - должны быть запросы к API метро и районов

## 🐛 Возможные проблемы

### Проблема: Не видна зеленая метка "Mobile Header Active"
- **Причина**: Не включен мобильный режим
- **Решение**: Включите Toggle device toolbar в DevTools

### Проблема: Фильтры не отображаются в строке поиска
- **Причина**: API options не загружены или проблема с состоянием
- **Решение**: Проверьте консоль браузера и диагностическую страницу

### Проблема: Фильтры не сохраняются после применения
- **Причина**: Проблема с actions.apply() или навигацией
- **Решение**: Проверьте Network tab на наличие правильных URL
