# Media UI Cleanup Complete

## Цель
Убрать лишнюю техническую информацию из UI медиатеки и сделать интерфейс более чистым, понятным и production-ready.

## Что изменено

### 1. Detail Page - Убрана техническая перегрузка

#### Удалено из основного блока "Информация о файле":
- ❌ `Storage Key` - внутреннее техническое поле
- ❌ `Public URL` - дублирует кнопку "Открыть в новой вкладке"
- ❌ `Checksum` - техническая информация для отладки

#### Оставлено в основном блоке (полезная информация):
- ✅ Имя файла
- ✅ Оригинальное имя
- ✅ Тип файла (JPG, PNG, WEBP и т.д.)
- ✅ Размер (форматированный)
- ✅ Размеры (width × height для изображений)
- ✅ Длительность (для видео)
- ✅ MIME тип (визуально вторично, мелкий шрифт)
- ✅ Расширение (визуально вторично, мелкий шрифт)

### 2. Создан Collapsible блок "Техническая информация"

Новый компонент: `src/components/admin/media/TechnicalInfoDisclosure.tsx`

Особенности:
- Свернут по умолчанию
- Содержит технические поля для отладки:
  - Storage Key
  - Public URL
  - Checksum
  - Proxy URL
- Визуально вторичный (мелкий шрифт, серый фон)
- Не занимает ключевое место в интерфейсе

### 3. Улучшена визуальная иерархия

#### Основной блок "Информация о файле":
- Крупные, читаемые значения для ключевых полей
- MIME тип и расширение - мелким шрифтом (text-xs, text-gray-600)
- Убраны длинные технические строки

#### Структура страницы:
```
Левая колонка:
  - Превью
  - Кнопка "Открыть в новой вкладке"
  - Действия (архивировать, удалить и т.д.)

Правая колонка:
  - Информация о файле (чистая, без техполей)
  - Метаданные (alt, title, caption)
  - Использование (usage map)
  - Системная информация (источник, даты)
  - Техническая информация (collapsible, свернут)
```

### 4. List Page - Без изменений

List page `/admin/media` уже был чистым:
- Показывает только полезные поля
- Нет raw publicUrl или storageKey в таблице
- Компактный и понятный формат
