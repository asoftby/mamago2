# Event Wizard - Participation Mode Icons

## Обзор

Добавлены премиальные иконки к вариантам `participationMode` в Event Wizard Step 5 для улучшения визуального восприятия и ускорения выбора.

## Иконки

Используется библиотека `lucide-react` (уже установлена в проекте).

### Mapping

```
participationMode     → Icon
─────────────────────────────────────
external-link        → Ticket
time-slots           → Clock
simple-booking       → UserPlus
request              → Send
info-only            → Info
```

## Визуальные характеристики

### Размер
- **18-20px** (w-5 h-5 в Tailwind = 20px)
- Не перегружает интерфейс
- Оптимальный баланс между видимостью и компактностью

### Цвет
- **По умолчанию**: `text-muted-foreground` (приглушенный серый)
- **При выборе**: `text-primary` (акцентный цвет)
- Плавный переход через `transition-colors`

### Позиционирование
- Иконка **слева** от текстового блока
- Выравнивание через `flex` + `gap-3`
- `flex-shrink-0` для предотвращения сжатия иконки
- `mt-0.5` для визуального выравнивания с текстом

### Структура
```tsx
<button>
  <div className="flex items-start gap-3">
    <Icon className="w-5 h-5 flex-shrink-0 mt-0.5" />
    <div className="flex-1 min-w-0">
      <div>Название</div>
      <div>Описание</div>
    </div>
  </div>
</button>
```

## Реализация

### Импорты

```tsx
import { Ticket, Clock, UserPlus, Send, Info } from "lucide-react";
```

### Структура данных

```tsx
const modes = [
  {
    value: "external-link",
    label: "Покупка билета по ссылке",
    description: "Билеты продаются на внешнем сайте",
    icon: Ticket,
  },
  {
    value: "time-slots",
    label: "Запись по времени (слоты)",
    description: "Для мастер-классов с выбором конкретного времени",
    icon: Clock,
  },
  // ...
];
```

### Рендеринг

```tsx
{modes.map((mode) => {
  const Icon = mode.icon;
  const isSelected = data.participationMode === mode.value;
  
  return (
    <button>
      <div className="flex items-start gap-3">
        <Icon 
          className={`w-5 h-5 flex-shrink-0 mt-0.5 ${
            isSelected ? "text-primary" : "text-muted-foreground"
          }`}
        />
        <div className="flex-1 min-w-0">
          <div className="font-medium text-sm">{mode.label}</div>
          <div className="text-xs text-gray-600">{mode.description}</div>
        </div>
      </div>
    </button>
  );
})}
```

## Семантика иконок

### Ticket (Покупка билета)
- **Значение**: Коммерческая транзакция
- **Ассоциация**: Билет, покупка, внешний сервис
- **Цвет при выборе**: Акцентный (коммерческое действие)

### Clock (Запись по времени)
- **Значение**: Временные слоты, расписание
- **Ассоциация**: Время, график, выбор слота
- **Цвет при выборе**: Акцентный (активное планирование)

### UserPlus (Простая запись)
- **Значение**: Добавление участника
- **Ассоциация**: Регистрация, запись, добавление
- **Цвет при выборе**: Акцентный (активное действие)

### Send (Оставить заявку)
- **Значение**: Отправка запроса
- **Ассоциация**: Сообщение, запрос, коммуникация
- **Цвет при выборе**: Акцентный (инициация контакта)

### Info (Только информация)
- **Значение**: Информационный контент
- **Ассоциация**: Справка, детали, без действий
- **Цвет при выборе**: Акцентный (но пассивное)

## Преимущества

### 1. Быстрое сканирование
- Иконки помогают быстро идентифицировать варианты
- Визуальные якоря для каждого типа взаимодействия
- Меньше времени на чтение текста

### 2. Улучшенная иерархия
- Иконка + название + описание = 3 уровня информации
- Четкая структура каждого варианта
- Легче различать похожие опции

### 3. Премиальный вид
- Современный дизайн
- Профессиональный интерфейс
- Соответствие трендам UI/UX

### 4. Консистентность
- Все иконки из одной библиотеки (lucide-react)
- Единый стиль stroke
- Одинаковый размер

### 5. Accessibility
- Иконки дополняют текст, не заменяют
- Текстовые лейблы остаются основным источником информации
- Цветовой контраст соблюден

## Технические детали

### Библиотека
- **lucide-react** v0.x
- Уже установлена в проекте
- Tree-shakeable (импортируются только нужные иконки)

### Размер бандла
- ~5 иконок × ~1KB = ~5KB
- Минимальное влияние на размер бандла
- Оптимизировано через tree-shaking

### Performance
- SVG иконки (векторные)
- Нет дополнительных HTTP запросов
- Быстрый рендеринг

### Browser Support
- Все современные браузеры
- SVG поддержка везде
- Fallback не требуется

## Альтернативные иконки (рассмотренные)

### Ticket vs ShoppingCart
- ✅ Ticket - более специфичная для билетов
- ❌ ShoppingCart - слишком общая

### Clock vs Calendar
- ✅ Clock - акцент на времени (слоты)
- ❌ Calendar - акцент на датах

### UserPlus vs UserCheck
- ✅ UserPlus - добавление участника
- ❌ UserCheck - подтверждение (не подходит)

### Send vs MessageSquare
- ✅ Send - отправка заявки
- ❌ MessageSquare - чат (не подходит)

### Info vs FileText
- ✅ Info - информация
- ❌ FileText - документ (не подходит)
