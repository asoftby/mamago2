# Event Wizard - Price Details Visual Guide

## До и После

### БЫЛО (режим "Цена от")

```
┌─────────────────────────────────────┐
│ СТОИМОСТЬ                           │
├─────────────────────────────────────┤
│                                     │
│ [Бесплатно] [Фиксир.] [Цена от] ✓   │
│ [По запросу]                        │
```

## Стилизация блока деталей

### CSS классы
```css
/* Контейнер блока */
bg-muted/50           /* Светлый фон */
rounded-lg            /* Скругленные углы */
p-4                   /* Внутренние отступы */
border                /* Граница */
border-border/50      /* Полупрозрачная граница */

/* Заголовок */
text-sm               /* Мелкий текст */
font-medium           /* Средняя жирность */
text-foreground       /* Основной цвет текста */
mb-2                  /* Отступ снизу */

/* Текст деталей */
text-sm               /* Мелкий текст */
text-muted-foreground /* Приглушенный цвет */
whitespace-pre-line   /* Сохранение переносов строк */
leading-relaxed       /* Увеличенная высота строки */
```

---

## Ключевые моменты

1. **Progressive Disclosure** - поле показывается только когда нужно
2. **Опциональность** - не обязательное поле
3. **Простота** - textarea, а не сложная таблица
4. **Понятный placeholder** - показывает формат
5. **Helper text** - объясняет назначение
6. **Визуальное выделение** - блок с фоном на странице события
7. **Сохранение переносов** - whitespace-pre-line
8. **Mobile-friendly** - адаптивная верстка
