# Обновление дизайна страницы события

## Что было сделано

Создан новый современный дизайн для страницы события на основе предоставленного HTML-шаблона.

## Изменённые файлы

1. **src/components/event-page/ModernEventPageView.tsx** (новый)
   - Новый компонент с современным дизайном в стиле Airbnb Experiences
   - Использует существующую структуру данных `EventPageData`
   - Адаптивный дизайн для мобильных и десктопных устройств

2. **src/app/(public)/[city]/events/[slugOrId]/page.tsx**
   - Обновлён импорт для использования `ModernEventPageView` вместо `EventPageView`
   - Все данные и логика остались без изменений

3. **src/components/event-page/index.ts**
   - Добавлен экспорт `ModernEventPageView`

## Основные особенности нового дизайна

### Структура страницы
- **Левая колонка (30%)**: Медиа-элементы
  - Постер события (соотношение 3:4)
  - Трейлер (если есть)
  - Вертикальное видео/рилс (если есть)

- **Правая колонка (70%)**: Основной контент
  - Заголовок и рейтинг
  - Описание события
  - Карточка бронирования с градиентной кнопкой
  - Расписание событий
  - Локация и контакты
  - Отзывы

### Дизайн-элементы
- Градиентные кнопки (#FF385C → #e21e4a)
- Тени и скругления для карточек
- Hover-эффекты на интерактивных элементах
- Sticky footer для мобильных устройств
- Адаптивная сетка для разных размеров экранов

### Цветовая схема
- Основной цвет: #FF385C (красный)
- Вторичный: #e21e4a (тёмно-красный)
- Фон: белый и оттенки серого
- Текст: серые оттенки для иерархии

## Как вернуться к старому дизайну

Если нужно вернуться к старому дизайну, просто замените в файле 
`src/app/(public)/[city]/events/[slugOrId]/page.tsx`:

```typescript
import { ModernEventPageView } from "@/components/event-page";
// на
import { EventPageView } from "@/components/event-page";
```

И замените все использования `<ModernEventPageView />` на `<EventPageView />`.
