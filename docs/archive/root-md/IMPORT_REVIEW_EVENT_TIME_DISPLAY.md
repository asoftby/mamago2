### 1. Функция извлечения времени

Создана функция `extractEventTime()` которая извлекает время из различных полей:

```typescript
function extractEventTime(nd: NormalizedEventImport): string | null {
  // 1. Проверяет стандартные поля времени:
  //    - time, startTime, endTime, startsAt, endsAt, eventTime, timeText
  
  // 2. Извлекает время из ISO строк startAt/endAt:
  //    - "2024-05-10T14:00:00" → "14:00"
  //    - Если есть оба → "14:00–16:00"
  //    - Если только начало → "с 14:00"
  
  // 3. Извлекает время из scheduleText:
  //    - Ищет паттерны "12:00", "14:30"
  //    - Одно время → "с 12:00"
  //    - Два времени → "12:00–14:00"
  //    - Несколько времён → "11:00, 13:00, 15:00"
  
  return null; // Если времени нет
}
```

**Поддерживаемые форматы:**

| Источник | Пример | Результат |
|----------|--------|-----------|
| `startTime` | "14:00" | "14:00" |
| `startAt` + `endAt` | "2024-05-10T14:00" + "2024-05-10T16:00" | "14:00–16:00" |
| `startAt` только | "2024-05-10T14:00" | "с 14:00" |
| `scheduleText` (одно время) | "Начало в 12:00" | "с 12:00" |
| `scheduleText` (два времени) | "с 10:00 до 18:00" | "10:00–18:00" |
| `scheduleText` (несколько) | "11:00, 13:00, 15:00" | "11:00, 13:00, 15:00" |

## Технические детали

### Извлечение времени

**Приоритет полей:**
1. Прямые поля времени (`time`, `startTime`, `endTime`, etc.)
2. ISO строки `startAt`/`endAt` (извлечение времени через regex)
3. Паттерны времени в `scheduleText` (regex `\b(\d{1,2}:\d{2})\b`)

**Regex для извлечения времени:**
```typescript
// Из ISO строки: "2024-05-10T14:00:00" → "14:00"
const timeMatch = nd.startAt.match(/T(\d{2}:\d{2})/);

// Из текста: "Начало в 12:00" → ["12:00"]
const timePattern = /\b(\d{1,2}:\d{2})\b/g;
const times = nd.scheduleText.match(timePattern);
```

### Форматирование

**Одно время:**
```typescript
return `с ${times[0]}`; // "с 12:00"
```

**Два времени:**
```typescript
return `${times[0]}–${times[1]}`; // "12:00–14:00"
```

**Несколько времён:**
```typescript
return times.join(', '); // "11:00, 13:00, 15:00"
```
