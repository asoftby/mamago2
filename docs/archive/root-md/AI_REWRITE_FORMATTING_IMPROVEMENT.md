# AI Rewrite: Улучшение форматирования текста

## Проблема

AI rewrite возвращал текст в виде одного большого абзаца или плохо структурированного текста:
- Цены шли одной строкой
- Перечисления не читались
- Отсутствовала визуальная структура

Это ухудшало UX и читаемость карточки события.

## Решение

Обновлён system prompt и user prompt для AI rewrite, чтобы результат был:
- Читаемым
- Структурированным
- Готовым к отображению в UI без дополнительной обработки

## Что изменено

**Было:**

  "Ты редактор текста для платформы mamaGo. Перепиши текст в заданном тоне. " +

  "Не выдумывай информацию и не дополняй текст от себя. Работай только с исходным текстом.";

  "3. Используй переносы строк для улучшения читаемости\n" +

## Правила форматирования

### 1. Абзацы
- Максимум 2-4 строки
- Разделяются пустой строкой

### 2. Списки
```
Программа:
— Пункт 1
— Пункт 2
— Пункт 3
```

### 3. Цены
```
Стоимость:
— 0 BYN — дети до 5 лет
— 30 BYN — общий билет
— 40 BYN — единый билет
```

### 4. Время
```
Время:
10:00–23:00
```

или

```
Время:
— Понедельник–пятница: 10:00–18:00
— Суббота–воскресенье: 10:00–20:00
```

### 5. Запрещено
- ❌ Markdown: `**жирный**`, `# заголовок`, `* список`
- ❌ HTML: `<b>`, `<br>`, `<p>`
- ❌ Сплошной текст без абзацев
- ❌ Добавление новой информации
- ❌ Пояснения типа "Вот переписанный текст"
