### 2. ✅ Заменены большие benefit-cards на компактный список

**Было**: 
- Большие карточки с padding `p-4`

**Стало**:

**Структура**:
```tsx

  - title: font-semibold, mb-0.5 (было mb-1)
  - description: text-xs, leading-relaxed
  - без border/shadow
  - flex gap-3 items-start
```

## Технические детали

### Цветовая система
- Primary: `#EF8759` (из `src/app/globals.css`)
- Primary с прозрачностью: `bg-[#EF8759]/10` для backgrounds
- Hover state: `hover:bg-[#EF8759]/90`
- Text color: `text-[#EF8759]`

### Spacing изменения
- Hero section: `pt-8 pb-6` (без изменений)
- Benefits section: `py-4` → `py-2` (меньше padding)
- Benefit items gap: `space-y-4` → `space-y-3` (плотнее)
- Icon container: `w-10 h-10` → `w-9 h-9` (компактнее)
- Title margin: `mb-1` → `mb-0.5` (плотнее)

### Layout изменения
- Убраны: `border`, `shadow-sm` у benefit items
- Добавлено: `items-start` для выравнивания иконок сверху
- Добавлено: `pt-0.5` для текстового блока (визуальное выравнивание)
- Example preview: `bg-neutral-100/50` → `bg-neutral-50` (чище)
- Example slots: добавлен `border border-neutral-200/30` (структура)
