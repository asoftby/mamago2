# Обновление CTA кнопок в блоке "Мой план"

## Описание изменений

Обновлена логика отображения текста кнопок выбора активностей в зависимости от наличия событий в выбранном дне.

## Изменённые компоненты

### 1. MyPlanWidgetV2.tsx
**Изменения:**
- Добавлена переменная `hasItemsInSelectedDate` для проверки наличия событий в выбранном дне
- Обновлён текст кнопки "Сама выберу" → "Поищу ещё" когда `hasItems = true`
- Обновлён текст кнопки "Выбрать из моих идей" → "Поищу ещё в идеях" когда `hasItems = true`
- Передача `hasItems` в компонент `EmptyPlanContent`

**Логика:**
```typescript
// Проверка наличия событий в выбранном дне
const hasItemsInSelectedDate = useMemo(() => {
  const selectedDateStr = format(selectedDate, "yyyy-MM-dd");
  const selectedDateItems = planItemsByDate?.[selectedDateStr] ?? [];
  return selectedDateItems.length > 0;
}, [selectedDate, planItemsByDate]);
```

**Тексты кнопок:**
- Кнопка 1 (AI рекомендации):
  - Пустой день: "Реши за меня"
  - Есть события: "Подкинь ещё вариков"
  
- Кнопка 2 (ручной выбор):
  - Пустой день: "Сама выберу"
  - Есть события: "Поищу ещё"
  
- Кнопка 3 (идеи):
  - Пустой день: "Выбрать из моих идей"
  - Есть события: "Поищу ещё в идеях"

### 2. RecommendationDecisionBlock.tsx
**Изменения:**
- Обновлён текст кнопки "Выбрать из идей" → "Поищу ещё" когда `hasItems = true`

**Тексты кнопок:**
- Основная кнопка (AI рекомендации):
  - Первый запрос: "Реши за меня" / "Подкинь ещё вариков"
  - Повторный запрос: "Ещё варианты"
  
- Дополнительная кнопка (идеи):
  - Пустой день: "Выбрать из идей (N)"
  - Есть события: "Поищу ещё (N)"

### 3. ManualChoiceButton.tsx
**Статус:** Уже содержал правильную логику, изменения не требуются

**Тексты кнопок:**
- Пустой день: "Сама решу"
- Есть события: "Поищу ещё"

## Поведение кнопок

Функциональность кнопок **не изменилась**, обновлены только тексты:

1. **"Подкинь ещё вариков" / "Реши за меня"**
   - Запускает генерацию AI рекомендаций
   - Показывает подборку событий на основе возраста, погоды и предпочтений

2. **"Поищу ещё" / "Сама выберу"**
   - Переход в каталог событий для самостоятельного выбора
   - Открывает главную страницу с фильтрами

3. **"Поищу ещё в идеях" / "Выбрать из моих идей"**
   - Открывает список сохранённых идей пользователя
   - Позволяет добавить события из личной коллекции
