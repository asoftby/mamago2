# Place Slug System - User Guide

## What is a Slug?

Slug - это человекочитаемая часть URL для публичной страницы места.

**Пример:**
- Админский URL: `http://admin.localhost:3000/admin/places/cmmj9eggc0009wsvnpqrmilie`
- Публичный URL: `http://localhost:3000/places/pugovka`

Slug = `pugovka` (часть после `/places/`)

## Как Работает

### Автоматическое Назначение

Slug назначается **автоматически** когда модератор публикует место (PENDING → PUBLISHED).

**Правила:**
1. Если название уникально в городе → короткий slug
   - "Пуговка" (единственная в Минске) → `pugovka`

2. Если есть дубли в городе → slug с улицей
   - "Пуговка" на Восточной → `pugovka-na-vostochnoy`
   - "Пуговка" на Притыцкого → `pugovka-na-pritytskogo`

3. Разные города не конфликтуют
   - "Пуговка" в Минске → `pugovka`
   - "Пуговка" в Бресте → `pugovka`

### Стабильность

**Slug НЕ меняется автоматически!**

Даже если владелец изменит:
- Название места
- Адрес
- Любые другие данные

Slug остается прежним для стабильности SEO.

### Кто Может Менять

- ❌ Владелец бизнеса - **НЕ может** менять slug
- ✅ Администратор/модератор - **может** изменить вручную (редко)

## Проверка Slug

### Для Конкретного Места

```bash
npx tsx scripts/check-place-url.ts <place-id>
```

Покажет:
- Текущий slug
- Публичный URL
- Историю изменений slug (если были)
- Другие места с таким же названием

### Для Всех Мест

```bash
npx tsx scripts/list-place-urls.ts
```

Покажет список всех опубликованных мест с их URL.

## Отображение в UI

### Публичная Страница

URL использует slug:
```
http://localhost:3000/places/pugovka-na-vostochnoy
```

### Название в Списках

Если в городе несколько мест с одинаковым названием, показывается улица:
- "Пуговка — Восточная"
- "Пуговка — Притыцкого"

Если название уникально:
- "Пуговка"

## История Slug

Если slug был изменен (администратором), старый slug:
- Сохраняется в истории
- Автоматически редиректит на новый URL
- Не ломает старые ссылки (SEO-friendly)

**Пример:**
1. Место создано со slug `pugovka`
2. Админ изменил на `pugovka-na-vostochnoy`
3. Старый URL `/places/pugovka` → редирект на `/places/pugovka-na-vostochnoy`

## FAQ

### Почему slug не меняется когда я меняю название?

Для стабильности SEO. Поисковики индексируют URL, и его изменение может навредить позициям в поиске.

### Как изменить slug?

Только администратор может изменить slug вручную. Обратитесь к администратору если нужно изменить.

### Что если два места на одной улице?

Система добавит номер:
- `pugovka-na-vostochnoy`
- `pugovka-na-vostochnoy-2`

### Slug содержит ошибку, как исправить?

Обратитесь к администратору. Он может изменить slug вручную, старый URL будет редиректить на новый.

### Можно ли использовать латинские названия?

Да, система автоматически транслитерирует кириллицу в латиницу:
- "Пуговка" → `pugovka`
- "Café" → `cafe`

## Технические Детали

### Формат Slug

- Только латинские буквы и цифры
- Слова разделены дефисом
- Все строчные буквы
- Без специальных символов

**Примеры:**
- ✅ `pugovka`
- ✅ `pugovka-na-vostochnoy`
- ✅ `cafe-bar-123`
- ❌ `Пуговка` (кириллица)
- ❌ `pugovka_na_vostochnoy` (подчеркивание)
- ❌ `pugovka на vostochnoy` (пробелы)

### Транслитерация

Используется стандарт BGN/PCGN для русского/белорусского:
- а → a, б → b, в → v, г → g
- ж → zh, х → kh, ц → ts, ч → ch
- ш → sh, щ → shch, ю → yu, я → ya
- і → i, ў → u (белорусские)

### Родительный Падеж

Для slug с улицей используется конструкция "на + родительный падеж":
- Восточная → vostochnoy (на Восточной)
- Притыцкого → pritytskogo (на Притыцкого)

Это более естественно звучит по-русски/белорусски.
