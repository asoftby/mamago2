# ТЗ 4. Занятия в мастере предложений (CLASS, PROGRAM) и открытие раздела «Занятия»

**Эталон:** `offer-wizard-prototype.html`, формат «Занятия и мастер-классы» (шаг 1 → «Занятия»).
**Опирается на:** TZ-1 (каркас 6 шагов), TZ-2 (услуги, `quoteOffer`, промо, расписание, бронь). Ограничения и «Защита от потерь» — из TZ-0.
**Цель:** партнёр за 5–7 минут описывает реальный кружок или секцию — группы, педагогов, тарифы, пробное, — а родитель на карточке выбирает группу, способ оплаты и записывается на пробное. После этого раздел «Занятия» открывается к наполнению.

---

## 1. Три вида занятий (шаг 1, после категории)

| Вид | Тип в БД | Что дальше |
|---|---|---|
| Регулярные занятия | `CLASS` | Группы по дням недели, абонементы, помесячно, пробное |
| Курс с началом и концом | `PROGRAM` | Даты курса, группы, «весь курс», присоединение после старта |
| Разовый мастер-класс | `CLASS` + флаг `oneOff` | Список дат, разовое / пробное |

Подписи шагов для занятий: 3 — «Тарифы и цены», 4 — «Группы и расписание».

## 2. Шаг 3 «Тарифы и цены»

- **Длительность занятия** — чипы 45 / 60 / 90 / 120 мин (одна на предложение).
- **Пробное занятие — отдельная опция**, не тариф: чекбокс «Есть пробное занятие» + цена (0 = бесплатно), один раз на ребёнка. Поля оффера: `trialEnabled`, `trialPrice`. Если включено — главная кнопка карточки «Записаться на пробное».
- **Тарифы** — список карточек. Тариф = услуга (`OfferModule`) с `kind = TARIFF` и полями:
  - `tariffType`: `SINGLE` | `PASS` | `MONTHLY` | `COURSE` (разовый мастер-класс — только SINGLE; регулярные — без COURSE; курс — без MONTHLY);
  - название (подставляется по типу, редактируется), цена *;
  - PASS: `lessonsCount`, `validDays`;
  - вычисляемое «≈ N BYN за занятие · −X% к разовому» (PASS: цена / занятий; MONTHLY: цена / (дней в неделю × 4); COURSE: цена / занятий курса).
- «+ Добавить тариф», удалить (если > 1).
- **Акции** (свёрнуто) — `ServicePromo` из TZ-2; для занятий «время визита» = ближайшее занятие выбранной группы.

## 3. Шаг 4 «Группы и расписание»

**Курс:** даты курса — одно поле с календарём диапазона (как у смен/промо), обязательно.

**Группа** (`ClassGroup`, по сути `OfferSession`-серия; итоговая модель — по аудиту фазы 0):
- возраст (текст «4–5» → `ageFrom/ageTo`), уровень: начинающие / продолжающие / любой;
- педагог — выбор из базы «Педагоги»;
- дни недели (кнопки), начало; длительность — из шага 3;
- мест, уже занято (вручную, пока записи не идут через mamaGo; дальше считается из броней) → «свободно N»;
- набор: «Идёт набор» | «Мест нет — лист ожидания» | «Старт с даты» (+ дата);
- где проходит — адрес филиала или «онлайн»;
- курс: «N занятий за курс» считается по дням группы внутри дат курса;
- заголовок карточки собирается сам: «4–5 лет · Пн, Ср 17:30» + пилюля статуса («3 места» / «лист ожидания» / «старт 24.10»).

**Педагоги** — общая база бизнеса (`Teacher`, ресурс `BookingUnit` типа PERSON): имя, фото, опыт; используется во всех занятиях. Удаление педагога → его группы переходят на первого из списка (с подтверждением).

**Разовый мастер-класс:** список дат (дата, начало, мест) — как сейчас.

Далее на шаге — общие блоки TZ-1/TZ-2: «Выходные и особые дни» (каникулы студии), «Как к вам записываются» (для занятий «Онлайн-запись» = «Выбирают группу и дату пробного»), «Так увидят родители».

## 4. Шаг 5 «Условия и контакты» — блок «Правила занятий»

- Пропущенное занятие: переносим | по справке | не переносим.
- Заморозка абонемента: нет | до 2 недель | до месяца (не для разовых).
- Курс: присоединиться после старта: можно, с перерасчётом | нельзя.
- Что взять с собой (текст).
Хранение — структурные поля (enum), не свободный текст: по ним будут фильтры.

## 5. Карточка для родителя

- **Группа:** список групп — «4–5 лет · начинающие», «Пн, Ср 17:30 · Анна Ковалёва», пилюля статуса. По умолчанию — первая группа, подходящая по возрасту ребёнка из профиля семьи.
- Курс: «Курс 19.10 – 14.12 · 17 занятий по 60 мин».
- **Как платить:** чип «Пробное · 15 BYN» (если включено, выбран по умолчанию) + чипы тарифов; под выбранным — «≈ 20 BYN за занятие · действует 30 дней».
- **Пробное:** ближайшие 3 даты выбранной группы (с учётом старта, дат курса, закрытых дней).
- Адрес группы, «с собой: …», акции (сработавшие строкой, остальные — подсказкой).
- Кнопка: «Записаться на пробное · 15 BYN» / «Записаться на бесплатное пробное» (пробное включено) | «Оставить заявку в группу» (без пробного или выбран тариф) | «Встать в лист ожидания» (группа полная).
- Под кнопкой: «Оплата — на месте, напрямую студии. Заявка бесплатная и ни к чему не обязывает.»
- Цена: `quoteOffer` = цена тарифа × детей − акция.

## 6. Заявки (сейчас) и бронирование (позже)

**Сейчас транзакций через mamaGo нет: любая запись — это заявка** (`BookingRequest`) со структурой: группа, дата пробного или тариф, ребёнок (возраст из профиля), контакт. Оплата — на месте у партнёра. Ниже — как заявка ведёт себя по видам; онлайн-удержание мест — вместе с фазой 3 TZ-2.

- Пробное: выбор конкретной даты группы → `BookingRequest` на 1 место этого занятия, удержание места до ответа.
- Абонемент / месяц / курс: заявка в группу → после подтверждения место в группе занято до конца периода (`seats` группы).
- Лист ожидания: `WaitlistEntry` (группа, ребёнок, контакт, дата); при освобождении места — уведомление первому в очереди, удержание на 24 ч.
- В «Записях» (TZ-3) колонки = педагоги и залы; занятия группы — повторяющиеся блоки с заполненностью «5/8».

## 7. Открытие раздела «Занятия» к наполнению

1. **Каталог `/{city}/zanyatiya`** (через `buildPublicPath`): фильтры — возраст ребёнка, категория, район/филиал, день недели, время (утро / день / вечер), цена за занятие (до N), «есть пробное», «бесплатное пробное», «есть места». Сортировка: подходящие по профилю ребёнка → ближайшее пробное → цена.
2. **Карточка в выдаче:** обложка, название, категория, возраст групп, ближайшее пробное, «от N BYN за занятие» (минимум из perLesson по тарифам), «есть места / лист ожидания».
3. **Онбординг партнёров:** короткая инструкция «Как добавить кружок за 5 минут» в кабинете; черновик из шаблона по категории (типовые тарифы и группы, которые партнёр правит).
4. **Импорт:** если расписание у партнёра в таблице или на сайте — импорт групп и тарифов (парсер по аналогии с family.by), результат — черновик на проверку партнёром.
5. **Персонализация:** интересы и возраст → занятия в подборках «Мой план» и в рекомендациях семье.

## 8. Эталоны для тестов

| Сценарий | Ожидаемо |
|---|---|
| Разовое 25, абонемент 8 занятий / 160 | «≈ 20 BYN за занятие · −20% к разовому» |
| Помесячно 140, группа Пн+Ср | «≈ 18 BYN за занятие · −28% к разовому» |
| Курс 19.10–14.12, группа Пн+Ср | 17 занятий |
| Пробное 15 (опция), группа Сб 11:00, акция −5 BYN выходные 10:00–13:00 | 10 BYN |
| Пробное выключено | кнопка «Оставить заявку в группу» |
| Пробное 0 BYN | «Записаться на бесплатное пробное» |
| Группа мест 10, занято 10 | статус «лист ожидания», кнопка «Встать в лист ожидания» |
| Группа «Старт с даты 24.10» | пробное не раньше 24.10 |

## 9. Критерии готовности

- [ ] Три вида занятий создаются, сохраняются, редактируются, отправляются на модерацию.
- [ ] Существующие CLASS/PROGRAM открываются без потерь: старые сеансы → группы (одна группа на сеанс), старая цена → тариф «Разовое».
- [ ] Педагоги — общая база; группа без педагога допустима (поле необязательно).
- [ ] Эталоны §8 — автотесты.
- [ ] Раздел `/{city}/zanyatiya` с фильтрами за фича-флагом; включаем, когда наполнено ≥ N предложений (N решает владелец).
- [ ] 360–390 px, светлая и тёмная тема.
