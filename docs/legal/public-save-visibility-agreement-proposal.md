# Предлагаемое дополнение к пользовательскому соглашению mamaGo.by

> Статус: проект редакции для юридического согласования. Не публиковать автоматически.
> Задача: #983, PR #985. Область применения: Event / Offer / Place.

## Публичное отображение сохранений

При сохранении события, предложения или места пользователем сервис mamaGo.by может учитывать такое действие для формирования общего количества сохранений соответствующей публикации.

Сервис может отображать количество пользователей, сохранивших публикацию, без раскрытия их личности.

Имя, фотография профиля (аватар) и факт сохранения конкретной публикации могут отображаться другим пользователям сервиса только при наличии отдельного добровольного согласия пользователя на такое отображение.

Пользователь вправе в любое время отключить публичное отображение своих сохранений в настройках конфиденциальности. После отключения его имя и фотография перестают отображаться в списках пользователей, сохранивших публикации.

Личные заметки, семейные планы, состав семьи, данные детей и содержимое приватных коллекций не подлежат публичному отображению в рамках данной функции.

## Правила реализации

- Условия должны быть дополнены понятным отдельным opt-in, не предзаполненным; отсутствие согласия = скрывать идентичность.
- В журнале согласий сохранять версию текста, дату согласия и отзыва; при отзыве сразу перестать отдавать публичный аватар.
- «Сохранить» должно работать без разрешения показывать аватар.
- Для существующих пользователей согласие отсутствует по умолчанию; задним числом не выдавать согласие.
- Контроль публичности через профиль/настройки конфиденциальности.
- Не относить «Поделиться» через системные мессенджеры к проверенным публичным репостам.
- Пользовательское соглашение является LEGAL Page в БД и управляется через CMS (см. src/app/(public)/legal/[slug]/page.tsx); этот файл не меняет опубликованную версию документа автоматически.
- До выпуска нужна юридическая проверка документа в связке с политикой обработки персональных данных и интерфейсом согласия.
