## API Integration

```typescript
// 1. Upload to CDN
POST /api/upload
Body: FormData with file

// 2. Save to Place
POST /api/business/places/[id]/images
Body: {
  url: string,
  width: number,
  height: number,
  blurhash: string,
  kind: "LOGO",
  sortOrder: 0
}

// 3. Update place.logoImageId (automatic)
```
