# Route Copy Proposals — 2026-07

Массовый первый проход копирайт-review для 14 импортированных маршрутов (97 стопов).
Это только предложения для просмотра — **в БД ничего не записано**, `--apply` не запускался.
Алексей утверждает пачкой, правит точечно только слабые места.

Каждый стоп: **Было** — первые ~200 символов исходной (уже очищенной от HTML) заметки;
**Предлагаю** — короткая версия 2–4 предложения, ≤200 символов (лимит поля в RouteEditor),
живой дружелюбный тон mamaGo, с сохранением конкретики (цены, часы, практические советы).

Пометки **⚠ потеря/разбивка** — где в исходнике важное не влезает в 200 символов
(несколько локаций/заведений в одном стопе, кандидат на разбивку). Пустых/бесполезных
исходников среди 97 стопов не найдено — везде есть за что зацепиться.
